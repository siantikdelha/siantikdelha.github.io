Setup Multi-Perangkat

Aplikasi ini sudah tersambung ke Cloud Firebase. Cara menggunakannya di banyak PC/Tablet:

  1. Host file HTML ini di internet (misal pakai GitHub Pages atau Hosting cPanel Anda).
  2. Buka alamat web (URL) di Tablet Pasien, lalu pilih mode "Tablet Pasien".
  3. Buka alamat web di Komputer Petugas, lalu pilih mode "Komputer Panggil".
  4. Buka alamat web di Smart TV (pakai browser TV), pilih mode "Layar TV Tampil".
  5. Semua akan otomatis sinkron (real-time) selama ada koneksi internet!

Reset Semua Antrean?

Nomor antrean akan kembali ke 0. Lakukan ini saat pergantian hari kerja.
