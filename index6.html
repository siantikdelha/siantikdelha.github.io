Cara Hubungkan Printer Thermal 80mm

📱 Di Tablet Android (Bluetooth/USB):

  1. Nyalakan Bluetooth Tablet & Sambungkan (*Pairing*) ke Printer Thermal 80mm.
  2. Install aplikasi gratis **RawBT** atau **ESC/POS Print Service** dari Google Play Store.
  3. Buka aplikasi RawBT, pilih printer Bluetooth Anda, dan atur ukuran ke **80mm**.
  4. Ketika tombol Poli ditekan di SIANTIK DELHA, tablet akan otomatis mencetak tiket tanpa perlu ketik manual!

💻 Di Komputer / Laptop Windows:

  1. Hubungkan kabel USB printer & install Driver Printer Thermal 80mm.
  2. Di Windows *Settings > Printers*, atur Printer Thermal 80mm sebagai **Default Printer**.
  3. Setel ukuran kertas ke **80mm x Receipt** di preferensi cetak.
